# Fable 5 App Concept Specs

A set of lightweight product-concept specs from the brainstorm session, each written to
be handed to **Fable 5** (`claude-fable-5`) as a build/expand prompt. Every spec ends with
a ready-to-paste **Fable 5 build prompt**.

These are *concept-stage* briefs (insight → user → mechanic → MVP → differentiation →
monetization → risk), not full engineering docs. Trojan Horse is the exception — it has a
full doc package already; here it appears only as a **status-quo snapshot**.

## How to use with Fable 5
Paste a spec's **Fable 5 build prompt** into a Fable 5 session. For comparison testing,
run the same prompt against another model and judge on originality, coherence, and taste.
